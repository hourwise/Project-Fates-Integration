## Priority interpretation

Priority is severity within the named capability class, not a global sequencing barrier. A P0 with `Blocks next recommended slice? = No` becomes mandatory before its capability class is enabled, but does not freeze narrower integration work.

- P0: security or architectural integrity prerequisite.
- P1: necessary for reliable operation or evidence, but can follow the first protected vertical path.
- P2: benchmark, adapter or product work that must not shape core contracts prematurely.
